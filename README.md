# Red Neuronal con Algoritmo LMS (Least Mean Squares)

Práctica académica enfocada en el entrenamiento de neuronas lógicas utilizando el algoritmo de Mínimos Cuadrados Medios (LMS) y el análisis del error por época con distintas tasas de aprendizaje ($\eta$).

## 📌 Descripción del Proyecto
Este repositorio contiene la implementación en Python del algoritmo LMS para entrenar compuertas lógicas (AND, OR, NAND, NOR, XOR). El programa evalúa el comportamiento del error cuadrático medio variando la tasa de aprendizaje $\eta$ y genera gráficas comparativas automáticas.
